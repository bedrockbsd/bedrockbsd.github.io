Downloading BedrockBSD

First of all, you have to have a working FreeBSD system.
Documentation can be found here



Secondly, run this incase you are on amd64:

fetch -o /tmp/bootstrapper-amd64.sh \
	https://bedrockbsd.github.io/bootstrapper-amd64.sh

chmod +x /tmp/bootstrapper-amd64.sh && /tmp/bootstrapper-amd64.sh
rm -f /tmp/bootstrapper-amd64.sh

That script, "bootstrapper-amd64.sh" ensures you have SSP strata manager in your $PATH.

You are done,
Enjoy!
