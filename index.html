Welcome to BedrockBSD.

BedrockBSD is an open-source BSD Operating system.
BedrockBSD is inspired from Bedrock Linux, much love and credits to them! :)

BedrockBSD does not work like Bedrock Linux; The BSD Version has a central strata managing tool called Strata Space Packages

If you wish to download BedrockBSD on top of FreeBSD, visit this page.



Update (1.0.0):

  • Added alpine, void, freebsd, and gentoo strata,
  • Fixed alpine's ethernet issues
